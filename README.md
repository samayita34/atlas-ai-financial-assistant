# Atlas AI Financial Assistant

An AI-powered Telegram financial assistant that provides personalized financial insights, real-time market data, financial document intelligence, and proactive daily briefings.

## Tech Stack

- Python
- FastAPI
- aiogram
- LangGraph
- Google Gemini
- Finnhub API
- SQLAlchemy
- Docker
